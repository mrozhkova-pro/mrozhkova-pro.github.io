# M.Rozhkova.Pro | Методист-разработчик

Одностраничный сайт-визитка Марины Рожковой, методиста-разработчика образовательных программ. Создаёт образовательные программы, которые приносят результат: методические комплексы под ключ — от концепции до готового УМК. Для образовательных организаций, учебных центров ДПО и компаний с корпоративным обучением.

## Стек

- Статический сайт на чистом HTML5.
- CSS — встроенный в `index.html` (адаптивная вёрстка, анимации).
- JavaScript — один встроенный скрипт (canvas-анимация в hero-секции, наблюдатель появления блоков).
- Без фреймворков, без сборщиков, без внешних шрифтов и библиотек.

## Структура проекта

| Файл | Назначение |
|---|---|
| `index.html` | Главная (и единственная) страница сайта — весь контент, стили и скрипты |
| `hero-bg.jpg` | Фоновое изображение hero-секции (используется как `background: url('hero-bg.jpg')`) |
| `.github/workflows/deploy.yml` | GitHub Actions workflow: автоматическая публикация на GitHub Pages |
| `.gitignore` | Служебные и секретные файлы, исключённые из репозитория |

## Где публикуется

- Публичный сайт: https://mrozhkova-pro.github.io/
- Публичный репозиторий (витрина GitHub Pages): `mrozhkova-pro/mrozhkova-pro.github.io`
- Исходный (приватный) репозиторий: `mrozhkova-pro/my-site`

## Схема деплоя

`push` в `main` репозитория `mrozhkova-pro/my-site` → GitHub Actions (`deploy.yml`) копирует файлы `index.html` и `hero-bg.jpg` в публичный репозиторий `mrozhkova-pro/mrozhkova-pro.github.io` → GitHub Pages публикует сайт.

## Как обновлять

1. Внести правки в `index.html` (тексты, стили, контакты).
2. Закоммитить: `git add index.html; git commit -m "Описание изменений"`.
3. Запушить в `main`: `git push`.
4. GitHub Actions автоматически переопубликует сайт (обычно ~15 секунд).

Деплой требует настроенного в приватном репозитории GitHub-секрета `PAGES_DEPLOY_TOKEN` с правами записи в публичный репозиторий.

## Локальная разработка

Сайт — статический, ничего устанавливать не нужно:

- **Простой способ:** открыть `index.html` в браузере двойным кликом.
- **Через локальный сервер:** `python -m http.server` в корне папки, затем открыть `http://localhost:8000/`.

## Требования

Минимальные: достаточно любого современного браузера. Бэкенд, сборка и зависимости не требуются.
